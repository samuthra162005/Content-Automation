# AEO Answer Box Templates & Formulas

Quick-reference templates for generating snippet-winning, AI-Overview-ready content blocks.

---

## 1. Definitive Formula (What Is / Meaning / Definition)

### Pattern:
> **[Query Term]** is a [broad category/system] designed to [primary function] by [specific operational mechanism]. Commonly used in [industry/context], it [key differentiator or primary business outcome]. For example, [concrete 1-sentence real-world use case].

### Example:
> **Programmatic SEO** is an automated search engine optimization methodology designed to publish large volumes of landing pages at scale by populating structured database records into uniform page templates. Commonly used by marketplaces and directory sites, it captures thousands of long-tail search queries without manual drafting. For example, TripAdvisor creates millions of city-specific hotel guide pages automatically using database variables.

## 2. Process / Step-by-Step Formula (How To)

### Pattern:
> To [achieve outcome], follow these [X] steps:
> 1. **[Action Verb 1] [Subject]**: [Crisp 10-15 word instruction].
> 2. **[Action Verb 2] [Subject]**: [Crisp 10-15 word instruction].
> 3. **[Action Verb 3] [Subject]**: [Crisp 10-15 word instruction].
> 4. **[Action Verb 4] [Subject]**: [Crisp 10-15 word instruction].
> 5. **[Action Verb 5] [Subject]**: [Crisp 10-15 word instruction].

### Example:
> To audit a website for Core Web Vitals, follow these five steps:
> 1. **Run Google PageSpeed Insights**: Inspect field data and lab data for target landing pages.
> 2. **Identify Interaction to Next Paint (INP) bottlenecks**: Look for long JavaScript tasks exceeding 200 milliseconds.
> 3. **Optimize Largest Contentful Paint (LCP)**: Preload hero banner images and configure server caching headers.
> 4. **Eliminate Cumulative Layout Shift (CLS)**: Set explicit height and width attributes on images and embed elements.
> 5. **Verify in Google Search Console**: Monitor the Core Web Vitals report to confirm site-wide field validation.
