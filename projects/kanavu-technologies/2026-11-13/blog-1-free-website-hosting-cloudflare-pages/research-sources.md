# Research Summary & Sources: How to Host a Website for Free Using Cloudflare Pages

## 1. Search Intent & Audience Analysis
* **Primary Query:** `How to Host a Website for Free`
* **Intent:** Practical How-To & Technical Guidance.
* **Audience:** First-time web creators and developers looking for zero-cost hosting that remains fast and does not sleep (unlike free Heroku/Render dynos).

---

## 2. Analyzed Reliable Sources
1. **Cloudflare Official Developer Docs (`developers.cloudflare.com/pages`):** Confirmed free tier specs: unlimited bandwidth, unlimited requests, 500 builds/month, 1 concurrent build, free automatic SSL/TLS.
2. **GitHub Docs (`docs.github.com`):** Git workflow and webhook integration for automated continuous deployment (CI/CD).
3. **MDN Web Docs — Static Sites & Hosting:** Explains the separation between static client files (HTML, CSS, JS) and server-side compute.
4. **Vercel & Netlify Pricing Comparison Studies:** Vercel caps free bandwidth at 100GB/month; Netlify caps at 100GB/month with overage charges. Cloudflare Pages is unique in offering zero bandwidth fees.
5. **W3Techs Web Server Statistics:** Cloudflare powers over 20% of the top 10 million websites worldwide.

---

## 3. Competitor Gaps Bridged
* **Bandwidth Cap Truth:** Competitors rarely mention that competitors like Vercel and Netlify charge steep overages if a site goes viral. Cloudflare Pages offers unlimited free bandwidth.
* **Dynamic Server Reality:** Competitors often confuse beginners by not clarifying that PHP/WordPress requires a database and cannot run directly on Pages without headless architectures.
