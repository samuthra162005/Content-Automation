# Visual Plan: How to Host a Website for Free Using Cloudflare Pages

## 1. Visual Strategy
* **Overall Goal:** Provide two distinct, technical diagrams illustrating git-based edge deployment and comparing conventional hosting against Cloudflare's serverless edge tier.
* **Aspect Ratio:** 16:9 widescreen landscape (`1536x864` or `1792x1024`).
* **Background:** Solid crisp white (`#FFFFFF`) with generous whitespace.
* **Canvas Typography:** Large bold header titles embedded directly on the image canvas in clean sans-serif typography.
