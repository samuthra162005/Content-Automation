# Research Sources & Fact-Checking Dossier: Power BI vs Tableau

## Primary Authoritative Sources

1. **Microsoft Learn: Power BI Architecture & DAX Overview**
   * URL: `https://learn.microsoft.com/en-us/power-bi/guidance/dax-overview`
   * Verification: Power BI uses the VertiPaq in-memory engine and Data Analysis Expressions (DAX) for tabular data modeling. Native integration with Microsoft 365 and Azure environments.

2. **Tableau Help Documentation: Visual Analytics & VizQL**
   * URL: `https://help.tableau.com/current/pro/desktop/en-us/vizql.htm`
   * Verification: Tableau utilizes VizQL (Visual Query Language) to translate drag-and-drop actions into structured database queries, specializing in visual discovery and multi-layered geospatial mapping.

3. **Gartner Magic Quadrant for Analytics and Business Intelligence Platforms**
   * URL: `https://www.gartner.com/en/documents/magic-quadrant-analytics-bi-platforms`
   * Verification: Microsoft (Power BI) and Salesforce (Tableau) consistently position as market Leaders based on vision completeness and execution ability.

4. **Aindhin Course Curriculum Dossier**
   * URL: `https://aindhin.com/courses/data-analytics`
   * Verification: Comprehensive training combining relational SQL data extraction with Power BI dashboard modeling and Tableau exploratory reporting.
