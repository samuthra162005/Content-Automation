# Research Sources: Relational Database & SQL Query Standards

## 1. Primary References
1. **ANSI/ISO/IEC 9075:2016 SQL Database Standard:**
   * Finding: Core clauses and standardized query execution sequence: `FROM` (identify tables) $\rightarrow$ `WHERE` (row filter) $\rightarrow$ `GROUP BY` (aggregate) $\rightarrow$ `HAVING` (group filter) $\rightarrow$ `SELECT` (column projection) $\rightarrow$ `ORDER BY` (sort) $\rightarrow$ `LIMIT` (restrict output).
2. **Beaulieu, Alan (2020). *Learning SQL: Generate, Manipulate, and Retrieve Data*. O'Reilly Media.**
   * Finding: Junior data analysts spend over 65% of their querying time on data filtering (`WHERE`), conditional aggregations (`SUM/COUNT/AVG`), and multi-table lookups (`LEFT JOIN`).
3. **Aindhin Curriculum & Course Documentation:**
   * Program: Data Analytics Certification Course (`aindhin.com/courses/data-analytics`). Modules: Advanced Excel, SQL Databases, Power BI & Tableau Visualizations, Hands-on Business Projects.
