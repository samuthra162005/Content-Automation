## Figure 2: Relational Database SQL JOINs Architecture

### 14-Field Structured Internal Design Brief
1. **Brand:** Aindhin
2. **Blog Title:** SQL for Beginners: Basic Queries Every Data Analyst Should Know
3. **H2 Section / Location:** Core SQL Clauses Reference Matrix (Figure 2)

5. **Image Purpose:** Clarify the mathematical and relational differences between INNER JOIN, LEFT JOIN, and RIGHT JOIN.
6. **Selected Visual Type:** `TECHNICAL_DIAGRAM` (Subtype: `RELATIONAL_JOIN_ARCHITECTURE`)
7. **Selection Rationale:** Relational table intersections are universally taught and understood via visual overlapping Venn set diagrams paired with table schema rows.
8. **Realistic Photography Required:** No.
9. **Illustration / Infographic Required:** Yes.
10. **Exact Product or Screenshot Assets Required:** No.
11. **Core Concept to Illustrate:** 3 primary JOIN types: INNER JOIN (matching intersection), LEFT JOIN (all left + matched right), and RIGHT JOIN (all right + matched left).
12. **Key Elements to Include:**
    - Large bold on-canvas headline: `RELATIONAL DATABASE SQL JOINS ARCHITECTURE`
    - Subtitle: `Visualizing Table Intersections: INNER JOIN, LEFT JOIN & FULL OUTER JOIN`
    - 3 distinct comparative diagram cards with overlapping set circles and sample customer/order schemas.
13. **Visual Style and Composition Notes:**
    - Pure white canvas background (`#FFFFFF`).
    - Color-coded set intersections with emerald green, sky blue, and amber highlights.
    - 16:9 widescreen (`1920 × 1080`), high legibility, clean vector styling.
14. **Specialized Prompt:**
    ```text
    A professional 16:9 technical diagram illustrating "Relational Database SQL JOINs Architecture".
    Headline: Bold on-canvas typography "RELATIONAL DATABASE SQL JOINS ARCHITECTURE" at top center.
    Subtitle: "Visualizing Table Intersections: INNER JOIN, LEFT JOIN & FULL OUTER JOIN" in emerald green (#10B981).
    Layout: 3 balanced architectural cards displaying table intersections:
    - Card 1: INNER JOIN (Only matching records between Table A & Table B highlighted).
    ```
