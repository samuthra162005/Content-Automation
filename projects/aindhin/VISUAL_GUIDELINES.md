# Aindhin Visual Guidelines (V7 Engine)

## 1. Visual Composition & Canvas Principles
* **Aspect Ratio:** 16:9 widescreen (`1920 × 1080` pixels).
* **Background Tone:** Clean pure white (`#FFFFFF`) with dark-slate tech containers (`#0F172A`) or soft gray card accents (`#F8FAFC`).
* **Title Typography on Canvas:**
  - Font Size: 40–44pt bold (`Segoe UI`).
  - Title Color: Slate 900 (`#0F172A`).
  - Subtitle Color: Tech Cyan / Sky Blue (`#0284C7`) or Emerald Green (`#10B981`).
* **Canvas Density:** Full canvas utilization with clean technical hierarchy.

---

## 2. Signature Visual Elements
* **Visual Categories:** `TECHNICAL_DIAGRAM`, `EDUCATIONAL_INFOGRAPHIC`, and `COMPARISON_MATRIX`.
* **SQL Visuals:** Query clause execution flow diagrams (FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY), relational table JOIN Venn/block diagrams, color-coded SQL syntax cards.
* **Power BI vs Tableau Visuals:** 2-column comparative decision matrix, data modeling vs visual discovery comparison, licensing and enterprise suitability breakdown.
* **Prohibited Visuals:** Fake salary screenshots, generic business handshakes, broken syntax, unreadable micro-code.
